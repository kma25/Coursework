# Базы данных Coursework

В проекте используются две отдельные базы PostgreSQL:

- `Coursework tester` - рабочая база для запуска `MainApp` и `SystemWatcher`.
- `Coursework test bsses` - запасная тестовая база, чтобы эксперименты и будущие интеграционные тесты не ломали рабочие данные.

Если обе базы уже созданы в pgAdmin, файл `create_databases_pgadmin.sql` запускать не нужно.

Для подготовки схемы откройте каждую базу отдельно и выполните `create_database.sql`:

1. Сначала в базе `Coursework tester`.
2. Затем в базе `Coursework test bsses`.

Скрипт создает таблицы, индексы, функции и ограниченные роли приложения. Учетная запись `postgres` нужна только для выполнения скриптов в pgAdmin, в рабочем коде она не используется.
